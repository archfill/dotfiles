# Hyprland 40%キーボード向けキーバインド設計

## 背景

40%キーボード（ZMKファームウェア）を使用しており、以下のキーがデフォルトレイヤーにない：

- 数字キー（1-9, 0）
- TABキー
- PRINTキー
- ファンクションキー

## 変更内容

### 1. ワークスペース操作（サブマップ方式）

**現状の問題**: `Super + 1-9` で数字キーにアクセスするためレイヤー切り替えが必要

**解決策**: サブマップ（モード）方式に変更

```
Super + W → ワークスペースモードに入る
  ├─ Q/W/E/R/T → ワークスペース 1-5 に切り替え
  ├─ H/L → 前/次のワークスペースへ移動
  ├─ Shift + Q/W/E/R/T → ウィンドウをWS 1-5に移動
  └─ ESC → モード抜ける
```

### 2. グループ（タブ）切り替え

**現状の問題**: `Super + TAB` でTABキーにアクセスするためレイヤー切り替えが必要

**解決策**: デフォルトレイヤーにある `,` `.` キーを使用

```
Super + , → 前のタブ (changegroupactive, b)
Super + . → 次のタブ (changegroupactive, f)
```

### 3. スクリーンショット

**現状の問題**: `PRINT` キーがデフォルトレイヤーにない

**解決策**: `Super + P` 系に変更（pseudo機能を削除）

```
Super + P → 範囲選択スクショ
Super + Shift + P → ウィンドウスクショ
Super + Ctrl + P → 画面全体スクショ
Super + Alt + P → 範囲選択 + 注釈ツール（satty）
```

## 削除される機能

- `pseudo` (疑似タイル) - 使用頻度が低いため削除
- 数字キーによるワークスペース切り替え - サブマップ方式に置き換え

## 残される機能

- `Super + TAB` によるグループ切り替え - 互換性のため残す（任意）
- `PRINT` キーによるスクショ - 外付けキーボード使用時のため残す
