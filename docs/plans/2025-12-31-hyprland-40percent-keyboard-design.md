# Hyprland 40%キーボード向けキーバインド設計

## 背景

40%キーボード（ZMKファームウェア）を使用しており、以下のキーがデフォルトレイヤーにない：

- 数字キー（1-9, 0）
- TABキー
- PRINTキー
- ファンクションキー

ただし、Super/Ctrl/Shift/Altはデフォルトレイヤーにあるため、通常のモディファイア組み合わせは使用可能。

## 設計方針

1. **Hyperキー** (`Ctrl+Shift+Alt+Super`) - ZMKで1キーに割り当て、即座にアクセスしたい操作に使用
2. **$mainMod (Super)** - 追加モディファイア（Shift/Ctrl/Alt）が必要な操作に使用
3. **サブマップは最終手段** - 操作数が多いカテゴリのみ使用（ワークスペース）

## カテゴリ別キーバインド

### A. アプリ起動系（Hyper対応）

| 操作                 | Hyperキー      | $mainModキー    |
| -------------------- | -------------- | --------------- |
| ターミナル           | `Hyper+RETURN` | `Super+RETURN`  |
| ファイルマネージャー | `Hyper+E`      | `Super+E`       |
| ランチャー           | `Hyper+D`      | `Super+D`       |
| クリップボード       | `Hyper+V`      | `Super+Shift+V` |
| 通知                 | `Hyper+N`      | `Super+N`       |
| チートシート         | `Hyper+/`      | `Super+/`       |

### B. ウィンドウ基本操作（Hyper対応）

| 操作               | Hyperキー     | $mainModキー  |
| ------------------ | ------------- | ------------- |
| 閉じる             | `Hyper+Q`     | `Super+Q`     |
| フローティング切替 | `Hyper+Space` | `Super+Space` |
| フルスクリーン     | `Hyper+F`     | `Super+F`     |
| スプリット切替     | `Hyper+J`     | `Super+J`     |

### C. ウィンドウ配置系（一部Hyper対応）

| 操作           | Hyperキー       | $mainModキー          |
| -------------- | --------------- | --------------------- |
| フォーカス移動 | `Hyper+H/J/K/L` | `Super+H/J/K/L`       |
| ウィンドウ移動 | -               | `Super+Shift+H/J/K/L` |
| リサイズ       | -               | `Super+Shift+矢印`    |
| モニター間移動 | -               | `Super+Ctrl+H/J/K/L`  |

### D. ワークスペース系（サブマップ）

モード入り: `Hyper+S` または `Super+S`

| 操作               | サブマップ内キー  | 動作         |
| ------------------ | ----------------- | ------------ |
| WS 1-5 切替        | `A/S/D/F/G`       | 1操作で解除  |
| 前のWS             | `H`               | 連続操作可能 |
| 次のWS             | `L`               | 連続操作可能 |
| ウィンドウをWS移動 | `Shift+A/S/D/F/G` | 1操作で解除  |
| モード解除         | `ESC` / `Enter`   | -            |

### E. グループ系（$mainModのみ）

| 操作             | $mainModキー          |
| ---------------- | --------------------- |
| グループ切替     | `Super+G`             |
| グループ前後     | `Super+,` / `Super+.` |
| グループに入れる | `Super+Alt+H/J/K/L`   |
| グループから出す | `Super+Shift+G`       |

### F. キャプチャ系（$mainModのみ）

| 操作               | $mainModキー    |
| ------------------ | --------------- |
| 範囲スクショ       | `Super+P`       |
| ウィンドウスクショ | `Super+Shift+P` |
| 全体スクショ       | `Super+Ctrl+P`  |
| 注釈付き           | `Super+Alt+P`   |

### G. システム系（Hyper対応）

| 操作                   | Hyperキー | $mainModキー |
| ---------------------- | --------- | ------------ |
| Hyprland終了           | `Hyper+M` | `Super+M`    |
| ウィンドウスイッチャー | `Hyper+C` | `Super+C`    |

## 変更点サマリー

- `Hyper+V` → クリップボード（`Shift+V`の代替）
- `Hyper+Space` / `Super+Space` → フローティング切替（`V`から変更）
- ワークスペースモード: `W` → `S`
- ワークスペース番号: `Q/W/E/R/T` → `A/S/D/F/G`（ホームポジション）
- ワークスペース前後移動（`H/L`）は連続操作可能
- グループ・キャプチャ系はHyperから削除
